Universal Existence Axiom (UEA) Framework
 
A Cross-Disciplinary Unified Framework Based on the Universal Existence Axiom, which breaks disciplinary barriers and provides a unified conceptual and logical foundation for complex systems science across physical, biological, psychological, social, technical, and civilizational domains.

Core Connotation
 
The UEA reveals "maintaining existence, cost-benefit optimization and dynamic equilibrium" as the underlying common logic of all complex systems. Constructed with 3 irreducible core axioms and 4 formal corollaries, the framework systematically explains the emergence, adaptation, evolution and collapse of complex systems in a self-consistent manner, and offers new analytical tools for AI safety, human behavior analysis, social governance and cross-disciplinary research.
 
Key Features
 
- Domain Independence: Applicable to both material and abstract systems, with no reliance on autonomous consciousness or specific material composition.
- Minimal Hypotheses: Maximum explanatory power for cross-domain system behaviors with only 3 core axioms.
- Empirical Verifiability: Verified through conventional, extreme and special scenario cases across 6 core fields of complex systems.
- Extensibility: Open framework for quantitative modeling and subdivision corollary supplementation for specific fields.
